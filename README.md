# СтройМаркет

Онлайн-магазин стройматериалов с учётом товаров на складе. Express + MySQL + EJS. Дизайн — чёрно-бордово-белый.

## Что реализовано

- Главная страница (`/`)
- Регистрация (`/register`) и авторизация (`/login`, пароли хранятся как bcrypt-хэш)
- Каталог (`/catalog`) с поиском и фильтром по категориям
- Карточка товара (`/product/:id`) с остатком на складе
- Корзина (`/cart`): изменение количества, удаление товара и очистка; при оплате остаток только проверяется, а уменьшается он позже — когда администратор переведёт заказ в статус «Выполнен»
- Добавление в корзину прямо из каталога кнопкой «В корзину», не заходя в карточку товара
- Фейковая оплата (`/payment`): пользователь вводит номер своей карты — поддерживаются Visa, Mastercard, Мир, American Express и другие карты от 13 до 19 цифр, платёжная система определяется по номеру; проверяются только длина номера (13–19 цифр), срок действия и CVC, реальные деньги не списываются, полный номер нигде не сохраняется, в заказе сохраняются статус оплаты, платёжная система и последние 4 цифры карты
- «Мои заказы» (`/orders`): пользователь видит свои заказы, их состав, сумму, статус оплаты и статус заказа (new / processing / completed / cancelled)
- Профиль (`/profile`): просмотр данных аккаунта, изменение имени и email, смена пароля (с проверкой текущего пароля и надёжности нового)
- Надёжность пароля при регистрации: минимум 8 символов, строчная и заглавная буквы, цифра и спецсимвол; на странице — шкала надёжности и чек-лист требований, на сервере — повторная проверка
- Админ-панель (`/admin`): добавление товаров, изменение остатков, удаление, смена статуса заказов; при смене статуса на `completed` остаток товаров заказа списывается со склада один раз (флаг `stock_deducted` в таблице `orders`)

## Запуск

1. `npm install`
2. Создать БД: `mysql -u root -p < database/schema.sql`
3. Добавить демо-товары: `mysql -u root -p stroymarket < database/seed.sql`
4. Указать в файле `.env` пароль root от MySQL (`DB_PASSWORD=...`, файл уже создан из `.env.example`) — без него будет `ER_ACCESS_DENIED_ERROR`
5. `npm start` — открыть http://localhost:3000

## Админ

Зарегистрируйтесь на сайте, затем в MySQL выполните:

```sql
UPDATE users SET role = 'admin' WHERE email = 'ваш@email';
```

После этого при входе откроется админ-панель.
